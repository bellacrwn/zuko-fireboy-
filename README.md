# Fireboy DML — ZUKO! Cinematic Experience

An unofficial cinematic storytelling website tracing Fireboy DML's journey from Abeokuta to the forthcoming **ZUKO!** era.

## Features

- Five interactive album eras with individual visual systems
- Dedicated discography and album story pages
- Swipeable Road to ZUKO! career timeline
- Responsive layouts for phones, tablets, and desktop
- ZUKO! boxing-round narrative
- Animated public career milestones
- Optional synthesized sound effects
- Hidden five-hit Easter egg
- Official album streaming and ZUKO! pre-save links
- Reduced-motion and mobile-performance safeguards

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

The production output is generated in `dist/`.

## Deployment

The included `vercel.json` provides SPA rewrites for direct access to discography and album routes on Vercel.
